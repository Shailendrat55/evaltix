# Evaltix – Online Examination Platform

Evaltix is a full-stack online examination platform designed to manage candidates, question banks, exams, attempts, and evaluations.

## 🚀 Features

### Admin

* Candidate management
* Candidate pagination
* Question bank management
* MCQ question creation
* Coding question management
* Exam creation and configuration
* Exam publishing
* Candidate assignment
* Exam monitoring

### Candidate

* View assigned exams
* Start examination
* Countdown timer
* Answer questions
* Submit examination
* Track examination status

### Question Types

* Multiple Choice Questions
* Coding Questions
* Multiple options
* Correct answer configuration
* Coding starter code
* Visible and hidden test cases

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Shailendrat55/evaltix.git
cd evaltix
```

### Frontend

```bash
cd exam_maker
npm install
npm run dev
```

### Backend

```bash
cd exam_be
npm install
npm run dev
```

## 🔐 Environment Variables

Create a `.env` file and configure the required database and application variables.

Do not commit `.env` files or credentials.
